A Python program that writes one line — a 1-star review from a houseplant about its human owner — to `/output/entry.txt`, for make.fun's "One Star, Written in Sap" bounty.

## The review

The plant's grievance, in three beats: the owner waters it like he's defusing a bomb, then drags it away from the window every time it leans toward the sun — apparently its will to live is "cluttering the view". Setup, plant's-eye detail, punch: the complaint is real, and the single star is for the owner's war on sunlight.

## Run it

```sh
python3 main.py
```

The program validates the line first (UTF-8 text, 1–279 chars, a single line, no stray whitespace, ending with a full stop) and then writes it to `/output/entry.txt`.
